# ไข่หวานช่วยได้ (kaiwan_chuaiduai)

ต้นแบบ (prototype) แอปขอคำปรึกษาพี่ไข่หวาน — ใช้ mock data ในหน่วยความจำ ไม่มี backend

## รัน

```bash
flutter run
```

## บัญชีทดลอง (รหัสผ่าน `1234`, แตะชิปที่หน้า login เพื่อกรอกอัตโนมัติ)

สมัครสมาชิกใหม่ได้ที่ปุ่ม "สมัครสมาชิก (sign in)" — บัญชีอยู่จนกว่าจะปิดแอป

## Flow

- **นักศึกษา**: หัวข้อ (กยศ / ทุนการศึกษา / การเรียน / สุขภาพจิต) → เรื่องที่ปรึกษา → เลือก
  "เจ้าหน้าที่คนไหนก็ได้" (เข้าแชททันที) หรือ "เลือกเฉพาะเจาะจง" → เลือกพี่ไข่หวาน → แชท
- **เจ้าหน้าที่**: หัวข้อ/เรื่อง มีกระดิ่งแจ้งเตือนจำนวนข้อความใหม่ → ส่วนรวม / ส่วนตัว (ส่งถึงฉันโดยตรง)
  → แชท (ถ้ามีห้องเดียวเข้าแชทเลย) → ปุ่ม **!!** มุมขวาบน = ระบบรายงาน
- ข้อความที่นักศึกษาส่งแบบเจาะจงจะไปถึงเฉพาะเจ้าหน้าที่คนนั้น
- โหมดจำลองการตอบกลับอัตโนมัติ เปิด/ปิดได้ที่หน้าโปรไฟล์

## โครงสร้าง

- `lib/data/` — models และ `MockStore` (ข้อมูลจำลอง + logic)
- `lib/screens/` — auth, student, staff, chat, profile
- `lib/widgets/common.dart` — การ์ดสีส้ม, กระดิ่งแจ้งเตือน, avatar
