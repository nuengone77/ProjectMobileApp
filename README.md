# ไข่หวานช่วยด้วย (kaiwan_chuaiduai)

ต้นแบบ (prototype) แอปขอคำปรึกษาพี่ไข่หวาน — เก็บข้อมูลในฐานข้อมูล SQLite บนเครื่อง (ไม่มี server)

- ปิดแอปแล้วข้อมูลยังอยู่ และจำการล็อกอินไว้จนกว่าจะกดออกจากระบบ
- รหัสผ่านเก็บเป็น hash (sha256) ไม่เก็บตัวจริง
- เปิดครั้งแรกจะใส่ข้อมูลตั้งต้นให้ (บัญชีเจ้าหน้าที่ 3 คน, นักศึกษาทดลอง, แชท/นัดตัวอย่าง)
- ปุ่ม "รีเซ็ตข้อมูลทดลอง" ในหน้าโปรไฟล์ = ล้างแล้วกลับเป็นข้อมูลตั้งต้น
- ข้อจำกัด: ข้อมูลอยู่เฉพาะเครื่องนี้ แชทข้ามเครื่องต้องมี server ภายหลัง

## Flow

- **นักศึกษา**: เลือกหัวข้อ 2 แบบ
  - **ถาม/ตอบเรื่องทั่วไป** → เลือกช่องทาง
    - **ที่ห้องกิจการนิสิต** → "เจ้าหน้าที่คนไหนก็ได้" (แจ้งเตือนทุกคน) หรือ "เลือกเฉพาะเจาะจง" → เลือกพี่ (แจ้งเตือนเฉพาะคนนั้น)
      → เลือกวันในปฏิทิน + เวลาจาก dropdown (ครั้งละ 30 นาที เลือกได้ทุกช่อง) → ส่งคำขอ → รอเจ้าหน้าที่ยืนยัน (ดูสถานะที่แท็บ "นัดหมาย")
      ถ้าพี่เสนอเวลาใหม่ กด "ตกลงเวลานี้" หรือ "เลือกเวลาอื่น"
    - **ผ่านแอป** → "เจ้าหน้าที่คนไหนก็ได้" (เข้าแชททันที) หรือ "เลือกเฉพาะเจาะจง" → เลือกพี่ไข่หวาน → แชท
  - **ขอความช่วยเหลือแบบเร่งด่วน** → เข้าแชททันที ส่งถึงเจ้าหน้าที่ทุกคน (แสดงเป็นสีแดง)
- **เจ้าหน้าที่**:
  - หน้าแรก: ตัวเลขสรุป + **ประวัติการปรึกษา** แยกหัวข้อ (ทั่วไป / เร่งด่วน) = แชทที่จบแล้วพร้อมสรุป (นัดหมายดูที่แท็บ "นัดหมาย")
  - แท็บ "ข้อความ": แชทที่ยังคุยอยู่ เรียงลงมา (เร่งด่วนที่ยังไม่อ่านขึ้นบนสุด) กรอง ทั้งหมด / ส่วนรวม / ส่วนตัว
  - **จบการปรึกษา** (เมนู … ในแชท): ต้องกรอก "เรื่องที่ปรึกษา" และ "คำปรึกษาที่เจ้าหน้าที่ให้"
    ถ้านักศึกษากดจบเอง เจ้าหน้าที่กด "บันทึกสรุป" ทีหลังได้
  - **ตารางสรุปเคส** (การ์ดในหน้าภาพรวม): เคสของฉันเรียงตามวันที่ กรองรายเดือน/กำหนดช่วงวันเอง และ ทั้งหมด/online/onsite
    - แถว online มาจากแชทที่จบแล้วอัตโนมัติ, แถว onsite กด "เพิ่มเคส onsite" เอง
    - แตะแถวเพื่อแก้ ประเภท/เรื่องที่ปรึกษา/คำปรึกษา/ระดับ (แก้เฉพาะในรายงาน ไม่กระทบแชท)
    - export (ปุ่มแชร์มุมขวาบน): CSV, PDF
  - แท็บ "นัดหมาย": คำขอนัดจากนักศึกษา เจ้าหน้าที่ตรวจเวลาว่างเอง แล้วกด "ยืนยัน สะดวกเวลานี้"
    หรือ "เสนอเวลาอื่น" (เลือกวัน/เวลาที่ตัวเองว่าง + ข้อความ) · ถ้าเวลานั้นมีนัดที่ยืนยันแล้วจะมีคำเตือน ⚠
- ข้อความที่นักศึกษาส่งแบบเจาะจงจะไปถึงเฉพาะเจ้าหน้าที่คนนั้น

## โครงสร้าง

- `lib/data/` — models, `MockStore` (logic + ข้อมูลในหน่วยความจำ), `app_database.dart` (SQLite), `registration_rules.dart`, `passwords.dart`, `report_export.dart` (CSV/PDF)
- `assets/fonts/` — ฟอนต์ Sarabun (OFL) ใช้วาดตารางใน PDF
- `lib/screens/` — auth, student, staff, chat, profile
- `lib/widgets/common.dart` — การ์ดเมนูสีพีช, กระดิ่งแจ้งเตือน, avatar
